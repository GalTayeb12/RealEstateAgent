# משימה: עיצוב מחדש של כל האתר לפי שפת Haveniq

> הוראות עבודה ל־Claude Code.
> **המקור לעיצוב:**
> - העמוד `/design-system`, הקוד שלו ו־`docs/DESIGN_SYSTEM.md`.
> - שתי תמונות ההדמיה ב־`docs/design/`: `haveniq-home.png` (דף הבית) ו־`haveniq-motion.png` (סיפור בתנועה).
>
> **המטרה:** כל עמוד, הודעה, חלון, מייל ומצב ריק באתר נראה כחלק מאותו מוצר. מקצועי, יוקרתי, רגוע ועתידני.

## 0. שפת העיצוב, כפי שהיא מופיעה בהדמיות

### צבעים
| תפקיד | תיאור | ערך התחלתי (לכייל מול `/design-system`) |
|---|---|---|
| רקע | שנהב חם, לא לבן | `#F5F2EC` |
| משטח | לבן חם לכרטיסים | `#FBFAF7` |
| ראשי | פטרול כהה, לכפתורים, כותרות וטקסט | `#123F40` |
| טקסט משני | פטרול מעומעם | `#4E6566` |
| מבטא | זהב מעומעם, למספרים, קווים, וי ומספרי סעיפים | `#B38B4D` |
| קווים | בז' עדין | `#E4DED3` |

- **הזהב:** משמש רק לקישוט ולמספרים גדולים, אף פעם לא לטקסט רץ, כי הניגודיות שלו על שנהב לא מספיקה.
- **צבעי סטטוס** (פנויה, שמורה, נמכרה, שגיאה, הצלחה): צבעים עמומים שמתאימים לפלטה, לא ירוק ואדום צעקניים.

### טיפוגרפיה
- **הסמל המסחרי "Haveniq":** פונט סריף אנגלי. לבדוק מה מוגדר ב־`/design-system`.
- **כותרות בעברית:** גדולות מאוד ובמשקל דק (300–400), עם נקודה בסוף. למשל: "יש הרבה בתים. אחד מהם שלך."
- **טקסט רץ:** עברית במשקל רגיל, באורך שורה של כ־65 תווים.
- **מספרי סעיפים:** "01", "02" בזהב, עם קו זהב דק לצידם.
- **מספרים גדולים:** "92%" ו־"12,400+", דקים וגדולים, עם `tabular-nums`.

### רכיבים שמופיעים בהדמיות
- **כפתור ראשי:** גלולה בצבע פטרול עם חץ ←, למשל "למצוא את הבית שלי".
- **קישור משני:** טקסט פטרול עם קו תחתון דק וחץ, למשל "ליזמים ולמוכרים".
- **כפתור מתאר:** גלולה עם מסגרת דקה, למשל "כניסה" בתפריט.
- **תווית צפה:** בסגנון זכוכית, עם קו שמוביל לנקודה בתמונה, למשל "92% התאמה · המחשה".
- **שורת נתונים:** מספרים גדולים עם מפרידים זהובים דקים.
- **רשימת וי:** עיגול זהב עם וי.
- **תמונות:** מלאות מקצה לקצה, עם מעבר רך לרקע.
- **כרטיסים:** רדיוס 14–16px וצל רך מאוד.

### עקרונות
- **אוויר:** הרבה מרווח לבן ומעט אלמנטים בכל מסך.
- **מטרה אחת לכל סעיף:** כל סעיף אומר דבר אחד, עם קריאה אחת לפעולה.
- **שקיפות:** כל נתון שאינו אמיתי מסומן "המחשה" או "לדוגמה", כמו בהדמיה.
- **תמונות:** בתאורת שקיעה זהובה, עם אבן בהירה, צמחייה ים־תיכונית וקו רקיע של העיר.

## 1. שלב ראשון: לימוד ותוכנית. לא לשנות קוד

1. קרא את `/design-system`, את הקוד שלו ואת `docs/DESIGN_SYSTEM.md`. אם יש סתירה בינם לבין ההדמיות, **ההדמיות קובעות**. רשום כל סתירה כזו.
2. מפה איפה מוגדר העיצוב היום: Tailwind config, CSS variables, ו־inline styles. מצא כמה צבעים קשיחים (hex) מפוזרים בקוד.
3. רשום את כל הרכיבים המשותפים: כפתורים, שדות, כרטיסים, חלונות, toasts, badges, טבלאות, טאבים, תפריט, פוטר, skeletons ומצבים ריקים.
4. רשום את כל 26 העמודים, ובנוסף:
   - דפי שגיאה: 404, 500 ו־error boundaries.
   - תבניות מייל: `lib/email.ts`.
   - הודעות מערכת: toasts, אישורים ושגיאות טופס.
5. בדוק אילו ספריות אנימציה קיימות (Framer Motion וכו') לפני שאתה מוסיף חדשות.
6. כתוב תוכנית לפי השלבים בסעיף 3, ועצור לאישור.

## 2. כללים

- **branch:** כל העבודה ב־`redesign`, וכל commit נדחף אליו. אין merge ל־main בלי אישור.
- **מקור אחד לעיצוב:** כל הצבעים, הפונטים, הרדיוסים, הצללים והמרווחים מוגדרים כ־tokens במקום אחד (CSS variables, וגם ב־Tailwind theme אם יש Tailwind). אסור hex קשיח ברכיבים. בסוף העבודה צריך להיות אפס צבעים קשיחים מחוץ לקובץ ה־tokens. זה ייבדק עם grep.
- **לא משנים לוגיקה:** רק תצוגה. API, Prisma וזרימות עסקיות לא משתנים.
- **RTL:** להשתמש ב־logical properties, למשל `margin-inline-start` במקום `margin-left`.
- **טקסטים:** כל טקסט חדש עובר דרך `messages.ts`.
- **נגישות:**
  - ניגודיות AA לכל טקסט.
  - focus גלוי לכל אלמנט שאפשר להגיע אליו במקלדת.
  - כל אנימציה מכבדת `prefers-reduced-motion`.
- **ביצועים:**
  - תמונות דרך `next/image`, בפורמט AVIF או WebP, עם `sizes` נכון.
  - תמונת ה־hero נטענת עם `priority`, וכל השאר ב־lazy.
  - פונטים דרך `next/font`.
- **תמונות:** אל תמציא ואל תוריד תמונות מהאינטרנט. תשתמש רק בקבצים שב־`public/images/brand/`. איפה שחסרה תמונה, שים placeholder מעוצב (גרדיאנט שקיעה עדין) ורשום ברשימה את מה שחסר.

## 3. שלבי עבודה

עצור בסוף כל שלב, ותן רשימת כתובות לבדיקה במחשב ובמובייל.

### שלב 1: יסודות
- **tokens:** צבעים, טיפוגרפיה, רדיוסים, צללים, מרווחים וזמני אנימציה.
- **פונטים:** טעינה דרך `next/font`.
- **`/design-system`:** מתעדכן כך שיציג את ה־tokens והרכיבים החדשים, ומשמש מעכשיו כמקור האמת החי.

### שלב 2: רכיבים משותפים
- **רכיבים:** כפתורים (ראשי, משני, מתאר, קישור עם חץ), שדות טופס, כרטיסים, חלונות, toasts, badges של סטטוס, טאבים, טבלאות, skeletons ומצבים ריקים.
- **תוויות:** תווית "המחשה" ותווית התאמה צפה.
- **מבנה:** תפריט עליון (לוגו בצד ימין, קישורים, "כניסה") ופוטר, כמו בהדמיה.

### שלב 3: דף הבית
- בנוי לפי `haveniq-home.png`, סעיף אחר סעיף:
  - hero
  - 01: מתוך העיר אל הבית שלך
  - 02: קודם נכיר אותך, עם היועצת
  - 03: ככה נראית התאמה
  - שורת נתונים
  - 05: ליזמים
  - קריאה לפעולה בסוף
  - פוטר
- **"סיפור בתנועה"** לפי `haveniq-motion.png`: מעבר בגלילה בין ארבעה רגעים:
  1. המבט הראשון: העיר מלמעלה.
  2. מתקרבים לבניין.
  3. מגלים את ההתאמה: קומה מוארת עם תווית 92%.
  4. נכנסים הביתה.

  עדיף לממש את זה כרצף של תמונות עם crossfade וזום עדין שמונע מהגלילה, ולא כוידאו כבד.
- **נתונים:** מספרים כמו "12,400+ קונים" נשארים מסומנים "נתונים להמחשה" עד שיהיו נתונים אמיתיים.

### שלב 4: עמודי המוצר
- **סדר:** עמוד הנכס והבניין (`/aom/...`), ואז הסיור, הראיון ו־LiveAvatar, העסקה (`/deal/...`), אזור אישי, הרשמה והתחברות.
- **הבניין התלת־ממדי:** שינוי האווירה בלבד, לפי ההדמיות:
  - תאורת שקיעה (שמש נמוכה וחמה, שמיים בגרדיאנט שקיעה).
  - אבן בהירה בחזית.
  - חלונות שמאירים בחום עדין.
  - עצי זית וקו רקיע רחוק.
  - הפאנלים והכרטיסים מסביב בשפה החדשה.

### שלב 5: ממשק היזם והניהול
- כל עמודי היזם והאדמין, באותה שפה, בגרסה צפופה יותר, כי אלה כלי עבודה.

### שלב 6: הודעות ומצבים
- **דפי שגיאה:** 404 ו־500 מעוצבים, עם משפט בסגנון המותג וכפתור חזרה.
- **מיילים:** תבניות מייל ב־HTML בשפה החדשה (לוגו, פטרול, שנהב), שנבדקות ב־Gmail ובמובייל.
- **הודעות:** toasts, אישורים, שגיאות טופס ומצבים ריקים. הטקסטים קצרים, ברורים ובטון המותג.

### שלב 7: בדיקה כוללת
- **צבעים:** grep לצבעים קשיחים, והתוצאה צריכה להיות אפס מחוץ ל־tokens.
- **כל עמוד:** במחשב ובמובייל, בלי שגיאות קונסול.
- **בדיקות:** `npm run build` ו־`npm test` עוברים.
- **Lighthouse:** בדף הבית, ביצועים ונגישות 90 ומעלה.
