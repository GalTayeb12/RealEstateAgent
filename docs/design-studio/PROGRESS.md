## M11 summary (2026-11-27) - catalog administration
- **Lifecycle** (`lib/studio/catalog/admin.ts`, pure): `status` on every manifest (draft -> review -> published -> retired -> published again; no skipping review). Missing status = published (older manifests). Only published + retired enter the index; retired entries stay resolvable for designs that pin them but are hidden from the drawer, swatches and the AI context.
- **Immutability gate** (in `publish.mts`): a published `(type, id, version)` whose content hash changed (status ignored) blocks publishing ("bump version"), and a published version may never disappear ("retire it instead"). It immediately caught a real mistake during this milestone (editing the handle default of three published v1 manifests); the edit was reverted.
- **Audit**: per manifest - license source URL, CC-BY attribution, GLB / preview / texture files exist, style tags, slot defaults exist and are of an allowed category, every slot has at least one choosable material, generator gates (M8).
